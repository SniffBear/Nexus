# Nexus Stitch

Read DESIGN.md and STITCH.md before changing UI.

Nexus is a dense, dark-first trading and social markets terminal. Preserve the established navigation, typography, tokens, semantic financial states, responsive behavior, and component language.

Never introduce a new visual language for an individual screen.

For financial UI:
- distinguish live, paper, delayed, and sample data
- never invent financial precision
- make consequential actions explicit and confirmable
- show risk and permission boundaries
- show concise AI sources and reasoning summaries, not private chain-of-thought

Use web-design-guidelines as the final accessibility audit.
Use design-taste-frontend selectively as an anti-slop visual guardrail; it is not the primary layout system for dense terminal screens.
