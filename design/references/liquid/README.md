# Liquid UX Reference

This directory documents external product references used to improve Nexus information architecture.

## Reference

Liquid: https://app.liquid.trade/

Use Liquid as a **UX/information-architecture reference only**.

Useful patterns to study:
- compact horizontal global navigation
- market ticker/context strip
- chart + order ticket composition
- order book and recent trades beside execution
- contextual Feed / News / Chat
- expandable bottom account tabs
- full-page Leaderboard, Calendar, Predict, Earn, and Search experiences
- configurable panel/layout settings
- light/dark application surfaces

## Do not copy

Do not copy:
- Liquid logo or branding
- proprietary assets
- exact colors
- exact typography
- exact visual identity
- proprietary illustrations or content
- screenshots as implementation targets

Nexus should borrow the interaction model and improve it with:
- Solana-native intelligence
- token safety
- wallet intelligence
- smart-money discovery
- AI analysis
- AI agents
- automation
- security
- execution/risk telemetry
